# mario-loop — そらループ (SORA LOOP)

ブラウザで遊べるオリジナルの横スクロールアクションゲームです。
`index.html` をブラウザで開くだけで遊べます（インストール不要・ファイル1つ）。

## 遊び方

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | ← → / A D | ◀ ▶ ボタン |
| ジャンプ（長押しで高く） | Space / Z / ↑ / W | ジャンプボタン |
| ダッシュ | Shift / X | ダッシュボタン |
| ポーズ | P / Esc | 画面タップで再開 |
| 音のON/OFF | M | — |

- コインを100枚集めると残機が1つ増えます。
- 敵は上から踏むと倒せます。続けて踏むとボーナス点が増えます。
- 光る木箱を下から叩くとコインが出ます。
- ステージの途中にチェックポイントの旗があります。
- ゴールの旗にたどり着くとクリアです。残り時間がボーナスになります。
- ステージは「昼 → 夕方 → 夜」とループしながら、少しずつ難しくなります。

## 主な特長

- キャラクターの足元を当たり判定の下端にぴったり合わせて描画しています（以前の「宙に浮いている」問題への対策）。地面に影も落ちます。
- 3層の丘と雲による視差スクロールの背景
- ジャンプの先行入力・崖際の猶予（コヨーテタイム）・可変ジャンプなどの気持ちよい操作感
- 効果音とBGM（Web Audio で生成）
- ハイスコアの保存（ブラウザ内）
